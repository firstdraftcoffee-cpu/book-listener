# Test report

Date: 24/11/26. Environment: Linux cloud machine, 2 CPU cores, Google Chrome (desktop engine) with a 390 x 844 phone-sized window. **No iPhone and no Safari/WebKit were available.** Every iPhone item is therefore listed as awaiting physical-device verification.

All books used are synthetic (generated by `scripts/make-fixtures.py`). No real manuscript was used.

## Requirement checklist
| Requirement | Status |
|---|---|
| PDF, EPUB, DOCX, TXT, Markdown, pasted text | Built, tested on synthetic files |
| Chapters, running header/footer removal, split-word repair, paragraphs, Unicode, footnotes, excluding bibliography/index/notes | Built, tested on synthetic files. Real publisher PDFs will differ; **needs trying on your own manuscripts** |
| Never rewrite the author's text | By design: speech text is separate from display text; tested that every spoken sentence maps to a range of the original |
| Local OCR for scanned PDFs | **Not built.** The app detects a scanned PDF and says so |
| Natural cadence, pauses, dates, currency, abbreviations, Irish names | Built and unit-tested. **Naturalness itself not judged (no audio heard)** |
| Voices: Irish, British, American, male and female, with previews | Catalogue built. Preview needs the voice engine on the device; each voice file is under 1 MB. Irish voice (Jenny) is female only, and its download and sound were **not tested** |
| Play/pause, resume, 15/30 s skip, chapters, speed 0.5 to 2.5, progress, time left | Built, tested in Chrome |
| Sleep timer, bookmarks, auto-save and recovery | Built, tested in Chrome (position recovery, bookmark saved). The timer was set but not waited out |
| Progressive generation with pre-buffering, audio cache | Built and tested |
| Lock-screen and Bluetooth controls, background playback | Built (Media Session, audio session, keep-alive). **Awaiting physical-device verification** |
| Proofreading tools: sentence highlight, tap to start, flags, notes, review, export notes | Built. Tested in Chrome (`tests/e2e/features.mjs`); exported files not opened in other apps |
| Custom pronunciation rules | Built, unit-tested |
| Chapter audio export | WAV per chapter built and tested on a tiny chapter (a full chapter takes about as long as it takes to narrate, on a slow CPU). M4B **not built** |
| Light and dark modes, accessible layout | Built. Contrast and VoiceOver **not checked** |
| Delete everything, privacy policy | Built, written and delete-all tested in Chrome |
| Offline operation | **Tested** in Chrome |

## Not tested (needs a real iPhone and your ears)
- Anything in Safari or the Home Screen app on iOS: lock screen, background audio, Bluetooth and headphone controls, phone calls and other interruptions, screen sleep, low-memory, battery use, hours of continuous play.
- How the voices sound, including the Irish accent and the Irish name lexicon.
- Download of voices from Hugging Face (blocked here). Only a copy served from a local test host was used, laid out the same way. Check this first on deployment.
- Piper / Jenny voice.
- The 8-hour "success test": a locked iPhone, hours without internet.
- Real manuscripts with tables, columns, images, and complex layout.
