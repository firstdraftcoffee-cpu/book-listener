Because the app downloads voices from their publisher's host rather than redistributing them, the app itself does not host any model. If you later host copies yourself (to avoid depending on Hugging Face), you become the distributor and must keep the licence texts alongside.

## FLAG: eSpeak NG is GPL-3.0
Both speech engines need to turn text into phonemes, and the `phonemizer` package does this with an eSpeak NG WebAssembly build, licensed GPL-3.0. Shipping GPL code inside a closed, sold app is a licensing problem. Options before commercial release:
1. Publish the app's source under GPL-3.0 (simplest, allows selling, but others may copy it).
2. Replace eSpeak NG with a permissively-licensed grapheme-to-phoneme method (a dictionary-based approach like Kokoro's own `misaki`, MIT) and re-test pronunciation.
3. Get a commercial licence or legal advice on whether loading eSpeak as a separately-delivered component changes the position.
This is the single biggest commercial risk found and is **unresolved**.
